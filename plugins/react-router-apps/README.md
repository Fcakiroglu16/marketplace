# React Router apps

The React Router team's official skills for framework mode, data mode and declarative mode routing.

Reviewed before publishing. Details, files and install options for every tool: https://playbookrun.com/p/react-router-apps

## Install

Claude Code:

```
/plugin marketplace add Fcakiroglu16/marketplace
/plugin install react-router-apps@playbookrun
```

Codex:

```
codex plugin marketplace add Fcakiroglu16/marketplace
codex plugin add react-router-apps@playbookrun
```

Cursor: a team admin imports https://github.com/Fcakiroglu16/marketplace as a team marketplace.

Pick the React Router mode that fits the app and follow the maintainers' patterns for routes, loaders, actions and navigation.
