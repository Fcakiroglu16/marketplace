# .NET testing

Official .NET skills to run, write and improve tests: filters, MSTest, coverage, gap analysis, test smells and testability.

## Install

Claude Code:

```
/plugin marketplace add Fcakiroglu16/marketplace
/plugin install dotnet-testing@playbookrun
```

Codex:

```
codex plugin marketplace add Fcakiroglu16/marketplace
codex plugin add dotnet-testing@playbookrun
```

Cursor: a team admin imports https://github.com/Fcakiroglu16/marketplace as a team marketplace.

Everything the .NET team ships for tests: running and filtering them on VSTest or Microsoft.Testing.Platform, writing new ones, finding untested code and fixing tests that prove little.
