# MSBuild and build performance

Official MSBuild skills with the binlog MCP server: diagnose failures, speed up builds, fix incremental builds and clean up project files.

## Install

Claude Code:

```
/plugin marketplace add Fcakiroglu16/marketplace
/plugin install msbuild-build-performance@playbookrun
```

Codex:

```
codex plugin marketplace add Fcakiroglu16/marketplace
codex plugin add msbuild-build-performance@playbookrun
```

Cursor: a team admin imports https://github.com/Fcakiroglu16/marketplace as a team marketplace.

Read binary logs instead of guessing: the binlog MCP server gives the agent the real build, and these skills turn it into fixes for failures, slow builds and messy project files.
