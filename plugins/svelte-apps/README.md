# Svelte and SvelteKit

The Svelte team's official skills and MCP server: Svelte 5 runes, best practices and an autofixer for generated components.

## Install

Claude Code:

```
/plugin marketplace add Fcakiroglu16/marketplace
/plugin install svelte-apps@playbookrun
```

Codex:

```
codex plugin marketplace add Fcakiroglu16/marketplace
codex plugin add svelte-apps@playbookrun
```

Cursor: a team admin imports https://github.com/Fcakiroglu16/marketplace as a team marketplace.

Write Svelte 5 and SvelteKit code that compiles the first time: the Svelte MCP server serves the current docs and checks components with its autofixer.
