# Windows Forms on modern .NET

The official Windows Forms skill: project setup, designer-friendly code, data binding, high DPI, accessibility and async UI on modern .NET.

Reviewed before publishing. Details, files and install options for every tool: https://playbookrun.com/p/windows-forms

## Install

Claude Code:

```
/plugin marketplace add Fcakiroglu16/marketplace
/plugin install windows-forms@playbookrun
```

Codex:

```
codex plugin marketplace add Fcakiroglu16/marketplace
codex plugin add windows-forms@playbookrun
```

Cursor: a team admin imports https://github.com/Fcakiroglu16/marketplace as a team marketplace.

Keep WinForms apps healthy on modern .NET: designer-safe code, binding, DPI and accessibility, as the WinForms team recommends.
