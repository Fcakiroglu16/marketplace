# Deno

The Deno team's skills: project config, npm and JSR dependencies, permissions, Fresh 2 frontends and moving Node or Bun projects to Deno.

Reviewed before publishing. Details, files and install options for every tool: https://playbookrun.com/p/deno

## Install

Claude Code:

```
/plugin marketplace add Fcakiroglu16/marketplace
/plugin install deno@playbookrun
```

Codex:

```
codex plugin marketplace add Fcakiroglu16/marketplace
codex plugin add deno@playbookrun
```

Cursor: a team admin imports https://github.com/Fcakiroglu16/marketplace as a team marketplace.

Deno projects from the Deno team: `deno.json`, npm and JSR packages, the permission model, frontends with npm frameworks or Fresh 2 islands, and moving an existing Node, npm, pnpm or Bun project over.
