# Software architecture patterns

Clean, onion and hexagonal (ports and adapters) architecture, DDD, CQRS and architecture decision records for any language.

## Install

Claude Code:

```
/plugin marketplace add Fcakiroglu16/marketplace
/plugin install software-architecture-patterns@playbookrun
```

Codex:

```
codex plugin marketplace add Fcakiroglu16/marketplace
codex plugin add software-architecture-patterns@playbookrun
```

Cursor: a team admin imports https://github.com/Fcakiroglu16/marketplace as a team marketplace.

Language-independent architecture guidance: Clean, onion and hexagonal layering with DDD building blocks, ports and adapters with examples in TypeScript, Java, Kotlin and Go, separate read and write models with CQRS, and decision records that keep the reasons behind each choice.
