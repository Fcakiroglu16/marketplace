# Nuxt full-stack

Nuxt 4 apps (SSR, data fetching, server routes, Nitro deploy presets) and Nuxt UI v4 components, with the official Nuxt and Nuxt UI documentation MCP servers.

## Install

Claude Code:

```
/plugin marketplace add Fcakiroglu16/marketplace
/plugin install nuxt@playbookrun
```

Codex:

```
codex plugin marketplace add Fcakiroglu16/marketplace
codex plugin add nuxt@playbookrun
```

Cursor: a team admin imports https://github.com/Fcakiroglu16/marketplace as a team marketplace.

Full-stack Nuxt: SSR and auto-imports, `useFetch` and middleware, Nitro server routes, caching, storage and deploy presets, and Nuxt UI v4 components, theming and forms. The official Nuxt and Nuxt UI MCP servers answer from the current documentation; no account needed.

## MCP servers

- **Nuxt docs**: The official Nuxt MCP server: searches and reads the Nuxt documentation, blog and modules. No account needed.
- **Nuxt UI**: The official Nuxt UI MCP server: components, their props, slots and examples, and the theming docs. No account needed.
