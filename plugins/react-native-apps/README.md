# React Native apps

Vercel's official React Native skill: performance, lists, animations, navigation and native modules in React Native and Expo apps.

## Install

Claude Code:

```
/plugin marketplace add Fcakiroglu16/marketplace
/plugin install react-native-apps@playbookrun
```

Codex:

```
codex plugin marketplace add Fcakiroglu16/marketplace
codex plugin add react-native-apps@playbookrun
```

Cursor: a team admin imports https://github.com/Fcakiroglu16/marketplace as a team marketplace.

Build smooth React Native and Expo apps with Vercel's rules for lists, animations, images and native code.
