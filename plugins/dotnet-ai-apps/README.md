# .NET AI apps

Pick the right .NET AI stack (Microsoft.Extensions.AI, Agent Framework, MCP, RAG) with the official skill and current Learn docs.

## Install

Claude Code:

```
/plugin marketplace add Fcakiroglu16/marketplace
/plugin install dotnet-ai-apps@playbookrun
```

Codex:

```
codex plugin marketplace add Fcakiroglu16/marketplace
codex plugin add dotnet-ai-apps@playbookrun
```

Cursor: a team admin imports https://github.com/Fcakiroglu16/marketplace as a team marketplace.

Choose between Microsoft.Extensions.AI, Microsoft Agent Framework, Semantic Kernel and MCP for an AI feature, then build it on current packages and docs.
